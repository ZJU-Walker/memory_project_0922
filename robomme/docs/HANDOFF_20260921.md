## 5. The method in one paragraph (what these runs are testing)

A pi0.5 policy that writes a short note to itself every second and reads its own notes back. Per memory tick (20
control frames for PickXtimes, 25 for BinFill) the model sees the front camera, the wrist camera, four past front
frames (0.2 s apart, pooled small) and a prompt with the goal and the joint state. Eight learned queries read a
fast-weight memory bank; the eight answers are added as tokens at the INPUT of the language model, so every layer
sees them. The model decodes a sentence ("pick up the second red cube"), and that sentence is written into the bank
token by token every tick, with the bank decaying 1 % per tick. Training is one run from the original pi0.5 weights:
early on the true label is written into the bank with probability 1, falling linearly to 0 at update 1500, after
which the model lives entirely on its own notes. Frozen: the image tower and the word embedder. The action expert
reads the memory only through a stop-gradient cache, so notes are trained by the sentence loss, not by the action
loss. Full detail with file:line citations is in `robomme/docs/0920_v0_plan.md`; the v3-to-v0 diff table is at the
top of `README.md`.

## 7. Gotchas that already cost time — do not rediscover them

- **The RoboMME recorder only stores HDF5 frames when `save_video=True`** (its buffering sits inside the video
  branch). With False every episode "succeeds" with 0 frames. The first generation attempt produced 100 empty files.
- **Zero write tokens never commit**, so anything that makes the visual bank inert must also mark the runtime state
  valid, or the v3.5 gate silently zeroes the loss on every decision tick. This was the bug that killed run 1
  (fixed 09-21 01:04, test `test_v0920_decision_ticks_keep_their_ce_and_flow_without_a_visual_commit`).
- **Never edit a bash script while it is running.** Bash reads by offset; copy to a new name instead.
- **`pgrep -f` inline in `bash -c` matches its own command line.** Use bracket patterns (`train[.]py ...`) or a script
  file.
- **Stale bytecode across hosts.** Every launcher must export `PYTHONDONTWRITEBYTECODE=1` and clear `__pycache__`;
  an edit on the workstation can otherwise have no effect on the node.
- **`export HOME=/iris/u/kewalk`** in every launcher (the AFS home quota kills caches).
- **The W&B init can freeze `train_<exp>.log`** while training continues. The live log is under
  `v35/wandb/wandb/run-*<id>/files/output.log`. Never declare a run stuck from the frozen file alone.
- **The training identity check refuses paths outside the project root**, which is why the pi0.5 base weights and
  `robomme/data` are hard-linked (`cp -al`) into this tree rather than symlinked.
- **Data probes belong on the node, not the workstation** (iris-ws-18 has 62 GB and OOMs silently).
