Boba Memory Training

Runs at a glance

Every v7 run continues the boba base checkpoint 9999. Lower CE and flow loss are better.

Memory policy · stage A then stage B

Stage A (updates 0–250): the sentence bank is written from the labels and the model learns to read it. Stage B (the next 1500 updates): the model writes its own sentences. Logged every 100 updates; pick the metric.

Phase-context ablation (ctx) · 2×H100

Four 5000-update continuations of the base that differ only in the prompt: ctx_none plain prompt (control) · ctx_prev adds the previous sentence "Last: …" · ctx_state adds the joint state of the last two 2 Hz ticks "Past: …" · ctx_both adds both. Training loss alone cannot rank them; the dev-episode evaluation decides.
